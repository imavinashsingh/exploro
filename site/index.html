Exploratory QA that remembers

Let an agent explore your site. Keep the proof.

Exploro is an open-source app for manual QA engineers. An agent tests your site in a real browser while you watch, learns how your app works as it goes, and turns every passed test into a regression suite that reruns without AI.

1 · Explore

You stay the tester. The agent does the clicking.

Paste a URL and describe what to test in plain words. The agent works through the flow scenario by scenario, in a browser that runs beside the chat.

  • Watch or take over. Step in at any point. Payments, deletions and other irreversible steps wait for your approval.
  • Passwords stay out of the chat. When a flow needs a login, the agent asks in a private sign-in card, and reports show a placeholder, never the password.
  • Evidence on disk. Each run ends with a Markdown and a self-contained HTML report: a verdict per scenario, screenshots, video, and the console and network errors behind them.
  • Stopped early? Save an interrupted test to memory so the next one still learns from it.
Verdicts you can trust5 verdicts
A wrong PASS is the worst result a tester can give. A verdict without a screenshot is stored as inconclusive, whatever the agent claimed.
  • PASSThe expected behaviour was seen and captured.
  • FAILThe site did something different, with the screenshot to show it.
  • BLOCKEDThe agent could not continue: a login, a missing approval, or a broken step.
  • INCONCLUSIVEThere is not enough evidence to say either way.
  • SKIPPEDOut of scope for this run, or you chose to leave it.

2 · Remember

Every test teaches the next one.

Group tests into a project and Exploro builds a memory of your app. The next test starts with a short brief and checks it against the live page, instead of rediscovering everything.

  • Facts are what a run saw, such as a validation message or where a link goes. Each one points at the screenshot that proves it.
  • Understanding is how the app works, such as “checkout needs a signed-in session”, written from runs and from what you told the agent.
  • A map of the app shows which pages are tested, failing, or seen but not tested yet.
  • You stay in charge. Confirm, edit or delete anything. Agents never change what you confirmed, and recall runs on your computer, offline.

3 · Replay

Explore once. Rerun it for free.

When a test passes, save it as a regression suite. Exploro replays the same steps and checks without a model, so it costs nothing to run as often as you like.

  • Visual checks. Each scenario is compared with a baseline screenshot, with the difference highlighted. Mask clocks and other content that changes every run.
  • Data sets. Import a CSV and replay the suite once per row, with values such as {{param:email}}.
  • Run them together. Replay every suite in a project side by side, from the app, the command palette, or the exploro regress command.
  • Honest results. A step that can't run is inconclusive, not a pass. Self-healing is off by default, and when on it only proposes a fix for you to accept.

Questions

Is there a macOS version?

Not as a download yet. Builds are Windows and Linux for now. On a Mac you can build from source.

What does it cost to run?

Exploro is free. Exploratory tests use the subscription or quota of the agent you pick. Regression replays use no model, so they cost nothing, unless you turn on self-healing for a suite.

Does my data leave my computer?

Exploro sends no analytics or usage data. It talks to the model provider you choose, through that provider's own CLI, and to the sites you ask it to test. Reports and project memory stay on your machine, and memory recall runs offline.

Why does Windows warn me about the installer?

The beta builds are not code-signed yet, so SmartScreen does not recognise them. Choose More info, then Run anyway, or build from source.

Will the agent change my code or my data?

It never edits code. It tests the deployed site, and anything irreversible, such as a payment, a deletion or sending a message, waits for your approval. Point it at a test or staging environment when you can.
